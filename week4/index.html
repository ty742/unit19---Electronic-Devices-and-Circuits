Core Anatomy

What Is an Operational Amplifier? (Golden Rules & Pinout)

⚡ The Ideal Op-Amp & The Two Golden Rules

An operational amplifier is a high-gain DC-coupled differential amplifier. It takes two inputs and amplifies the difference between them.

Golden Rule 1: Zero Input Current ($I_+ = I_- = 0$)
The input impedance is practically infinite ($R_{in} \approx 10^{12}\,\Omega$). No current flows into either input terminal!
Golden Rule 2: Virtual Short ($V_+ = V_-$)
When negative feedback is connected, the op-amp output drives until the inverting input $(-)$ equals the non-inverting input $(+)$.

Part 1: The Open-Loop Comparator (Decision Maker)

🔍 How an Open-Loop Comparator Operates

When an op-amp has no feedback path, it operates in open-loop mode. Because the open-loop gain is gigantic ($A_{OL} \approx 100{,}000+$), even a microscopic difference between inputs drives the output directly to its power rails.

The Switching Decision:
  • If $V_{in} > V_{ref} \implies$ Output snaps HIGH ($\approx +V_{CC} - 1.5\text{ V}$)
  • If $V_{in} < V_{ref} \implies$ Output snaps LOW ($\approx 0\text{ V}$)

In our factory scenario: $V_{ref} = 0.50\text{ V}$. If the sensor drops below $0.50\text{ V}$, the comparator detects a pressure loss and outputs a digital LOW.

Foundational Principle

Why Feedback? The Magic of Negative Feedback

🚗 The Speedometer Analogy

Imagine driving a powerful racing car on a motorway with your eyes closed to the speedometer. The engine is so powerful that any slight depression of the accelerator drives the car to maximum speed.

The speedometer provides feedback. By observing the speedometer and easing off the throttle, you hold a steady, predictable 70 mph regardless of road gradient or wind.

Electronic Negative Feedback:
We return a controlled portion of the output voltage back to the inverting input ($-$). This subtracts from the input, self-correcting the amplifier and turning an erratic $100{,}000$ open-loop gain into a rock-solid, predictable closed-loop gain!

Feature Open-Loop Closed-Loop
Feedback Path? None (Open) Yes (Negative to $-$)
Voltage Gain ($A_v$) $\approx 100{,}000$ (Uncontrolled) Set by external resistors
Output Behavior Snaps to Saturation Rails Faithful linear replica

Part 2: The Non-Inverting Amplifier ($A_v = 1 + R_f / R_1$)

📐 Circuit Operation & Derivation

In a non-inverting amplifier, the sensor signal $V_{in}$ connects directly to the non-inverting terminal $(+)$. Because no current enters the $(+)$ input, the circuit presents an extremely high input impedance, preventing sensor loading.

Non-Inverting Voltage Gain Formula:
$$A_v = 1 + \frac{R_f}{R_1}$$
$$V_{out} = V_{in} \cdot \left(1 + \frac{R_f}{R_1}\right)$$

Phase Relationship: The output signal is in-phase ($0^\circ$) with the input. When input rises, output rises!

Part 3: The Inverting Amplifier ($A_v = -R_f / R_{in}$)

🔄 Inversion & Virtual Earth Concept

In an inverting amplifier, the non-inverting terminal $(+)$ is tied to Ground ($0\text{ V}$). Due to Golden Rule 2 ($V_+ = V_-$), the inverting terminal $(-)$ is also held at Virtual Earth (0 V)!

Inverting Voltage Gain Formula:
$$A_v = -\frac{R_f}{R_{in}}$$
$$V_{out} = -V_{in} \cdot \frac{R_f}{R_{in}}$$

Phase Relationship: The negative sign represents a $180^\circ$ phase inversion. When input swings positive, output swings negative!

Figure 4.3: Inverting Op-Amp ($R_{in} = 1\text{ k}\Omega, R_f = 10\text{ k}\Omega \implies A_v = -10$)
